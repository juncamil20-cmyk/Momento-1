# Casa Nativa

Landing page responsive para **Casa Nativa**, un refugio rural pensado para desconectarse del ruido, disfrutar de la naturaleza y vivir una experiencia tranquila cerca de la ciudad.

Este proyecto fue desarrollado como parte del taller de exploración de frameworks CSS.

---

## Descripción del proyecto

Casa Nativa es una landing page enfocada en presentar una experiencia de alojamiento rural.

La página permite mostrar:

- La identidad de Casa Nativa.
- La experiencia y servicios ofrecidos.
- Información de contacto.
- Un formulario de solicitud de reserva.
- Una navegación responsive para dispositivos móviles y escritorio.

El proyecto utiliza **UIkit** como framework CSS y **Anime.js** para agregar animaciones a la navegación y a las tarjetas de servicios.

---

## Framework asignado

### UIkit

**UIkit** fue el framework CSS asignado para el desarrollo de este proyecto.

### Método de instalación

UIkit fue integrado mediante **CDN**, utilizando sus archivos de estilos, JavaScript e iconos directamente desde jsDelivr.

```html
<link
    rel="stylesheet"
    href="https://cdn.jsdelivr.net/npm/uikit@3.25.25/dist/css/uikit.min.css"
/>

<script src="https://cdn.jsdelivr.net/npm/uikit@3.25.25/dist/js/uikit.min.js"></script>

<script src="https://cdn.jsdelivr.net/npm/uikit@3.25.25/dist/js/uikit-icons.min.js"></script>
